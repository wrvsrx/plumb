SETUP                                                            *plumb-setup*

plumb.nvim requires Neovim 0.12 and a `plumb` binary. Add contrib/nvim to
'runtimepath', then call:
>
  require('plumb').setup()
<
No mappings are installed. The defaults enable LSP, CodeLens, and search.
Features can be disabled independently:
>
  require('plumb').setup({
    command = 'plumb',
    lsp = {
      enabled = true,
      root_markers = { '.plumb', '.git' },
    },
    codelens = { enabled = true, picker = 'quickfix' },
    search = { enabled = true, picker = 'native' },
  })
<
Use picker = 'snacks' when snacks.nvim is installed. Repeated setup calls are
safe and replace the plugin's commands and autocmds.

The plugin does not modify window-local folding options. `plumb lsp` provides
folding ranges and task collapsedText; configure vim.lsp.foldexpr() and
vim.lsp.foldtext() in the editor when desired.

Completed and canceled task semantic tokens cover the complete task block and
default to the Comment highlight. Override these groups to customize them:
>
  @lsp.typemod.task.completed.plumb
  @lsp.typemod.task.canceled.plumb
<

=============================================================================
COMMANDS                                                      *plumb-commands*

:PlumbNotes           Search workspace notes.
:PlumbTasks           Search ready workspace tasks.
:PlumbReferences      Run the reference CodeLens at the cursor.

=============================================================================
LUA API                                                            *plumb-api*

require('plumb').setup(opts)                  Configure the complete plugin.
require('plumb').config()                     Return effective configuration.
require('plumb.search').search_notes(opts)    Search notes.
require('plumb.search').search_tasks(opts)    Search tasks.
require('plumb.search').live_search(...)      Adapter-driven cancellable search.

=============================================================================
HEALTH                                                          *plumb-health*

Run :checkhealth plumb. It checks Neovim, the binary version, and active plumb
LSP clients. Tree-sitter parsers and queries are installed and configured
separately from plumb.nvim.
