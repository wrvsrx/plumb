SETUP                                                            *plumb-setup*

plumb.nvim requires Neovim 0.12 and a `plumb` binary. Add contrib/nvim to
'runtimepath', then explicitly configure the plugin before opening a plumb
buffer:
>
  require('plumb').setup({
    command = 'plumb',
    lsp = {
      enabled = true,
      root_markers = { '.plumb', '.git' },
    },
    codelens = { enabled = true, picker = 'quickfix' },
    search = { enabled = true, picker = 'native' },
  })
<
No mappings are installed. The defaults enable LSP, CodeLens, and search.
Features can be disabled independently. Search and CodeLens implementation
modules are required only when their commands are executed. Plugin managers may
still defer the complete plugin by filetype when desired.

The standard ftplugin sets buffer-local 'expandtab', 'shiftwidth'=1, and
'softtabstop'=-1 for plumb buffers. It restores those options when the filetype
changes. It leaves 'tabstop' unchanged so literal tabs in verbatim payloads use
the user's display width.

Use picker = 'snacks' when snacks.nvim is installed. Repeated setup calls are
safe and replace the plugin's commands and autocmds.

The plugin does not modify window-local folding options. `plumb lsp` provides
folding ranges and task collapsedText; configure vim.lsp.foldexpr() and
require('plumb').foldtext() in the editor when desired. WAITING, BLOCKED, DONE,
and CONFLICTED retain their DiagnosticInfo, DiagnosticHint, Comment, and
DiagnosticWarn links. CANCELED combines the resolved Comment color with the
DiagnosticDeprecated strikethrough. Other fold labels retain the
native vim.lsp.foldtext() result. Whole-document formatting
uses changed-line edits, so native vim.lsp.buf.format() and format-on-save
preserve fold overrides on unchanged blocks. The server returns same-line task
and event ranges to lineFoldingOnly clients. Editors that support these ranges
also need foldminlines=0 to close a one-screen-line fold. Upstream Neovim 0.12's
LSP fold adapter ignores them; this plugin does not add a folding-range adapter.

Completed and canceled task semantic tokens cover the complete task block and
default to the Comment highlight. Override these groups to customize them:
>
  @lsp.typemod.task.completed.plumb
  @lsp.typemod.task.canceled.plumb
<

=============================================================================
COMMANDS                                                      *plumb-commands*

:PlumbNotes           Search workspace notes.
:PlumbTasks           Search ready workspace tasks.

=============================================================================
LUA API                                                            *plumb-api*

require('plumb').setup(opts)                  Configure the complete plugin.
require('plumb').config()                     Return effective configuration.
require('plumb').foldtext()                   Render LSP fold text with task highlights.
require('plumb.search').search_notes(opts)    Search notes.
require('plumb.search').search_tasks(opts)    Search tasks.
require('plumb.search').live_search(...)      Adapter-driven cancellable search.

=============================================================================
HEALTH                                                          *plumb-health*

Run :checkhealth plumb. It checks Neovim, the binary version, and active plumb
LSP clients. Tree-sitter parsers and queries are installed and configured
separately from plumb.nvim.
